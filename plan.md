MVP — Shared Chore Manager
Target user: Roommates
Core problem:

“Who is responsible for what?”
Core experience
Create a household
Invite/join roommates
Anyone can create a chore
Each chore is a simple task
Each chore is assigned to one roommate
Everyone sees one shared chore list
Each chore shows who is responsible
The assigned roommate can mark it Done
No deadlines
No schedules
No automatic rotation
No complicated fairness algorithm
Example
Household: Apartment 4B
☐ Take out trash — Alex
☐ Clean kitchen — Sarah
☐ Vacuum living room — Mike
☑ Clean bathroom — Alex

The product's core promise
“Everyone knows who is responsible for what.”
I would not add more features yet. Next, we should explore the roommate's actual experience/problem and then decide whether anything else truly belongs in the MVP.
